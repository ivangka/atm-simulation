# ATM Simulation

ATM Simulation is a console application implemented in Java. The program provides basic functionality to manage bank accounts through a text-based menu. It allows users to authorize, create accounts, deposit and withdraw funds, transfer money between accounts, and view transaction history.

## Project Structure

`ATM`, `Bank`, `User`, `Account`, `Transaction`.
